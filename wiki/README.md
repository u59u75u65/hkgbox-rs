# hkgbox-rs Wiki

This directory contains project documentation, analysis reports, and development plans for the hkgbox-rs project.

## Structure

```
wiki/
├── Home.md                      # Project overview and quick start
├── Project-Modernization-2026.md # Dependency modernization details
├── API-Migration-Analysis.md     # HKGolden API analysis and migration plan
├── Roadmap.md                   # Development phases and release planning
└── README.md                    # This file
```

## Purpose

The wiki serves as:
- **Historical record**: Documents major changes and migrations
- **Technical reference**: API details, architecture decisions
- **Planning tool**: Roadmaps and future work
- **Knowledge base**: For contributors and maintainers

## Contributing

When making significant changes to the codebase:
1. Document the analysis in the wiki
2. Update relevant roadmap items
3. Keep pages up-to-date as work progresses
4. Cross-reference related pages

## Formatting

- Use standard Markdown syntax
- Include code examples with syntax highlighting
- Add diagrams where helpful (ASCII or Mermaid)
- Update "Last Updated" timestamps
- Sign major contributions
